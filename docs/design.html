Kipple · visual language

Fight the kipple.

Warm, calm and a little cheeky. This is the visual language of Kipple, the open-source file organiser for Linux, macOS and Windows. Eggshell and yolk by day, a night coop by night.

01

Foundations

Colour, type, shape and the hen. All colours are semantic tokens with a light and a dark value. Components never use raw hex values.

Colour tokens

Eggshell light

Night coop dark

Rules: Yolk is the one accent and is reserved for primary actions, selection and the brand. Comb (red) is only for destructive actions (Trash, delete). Sage means "keep / space saved". Confidence is shown with eggs, never with red/green, so it stays readable for colour-blind users. All text pairs meet WCAG AA (≥ 4.5:1); body text is 15–17:1.

Type colours are muted on purpose: they help scanning lists, but never compete with Yolk or Comb. A chip always pairs colour with an icon and a label.

02

Components

The building blocks, implemented in the app with Radix primitives and Tailwind tokens. Every interactive element has hover, active, focus-visible and disabled states.

Buttons

Primary (Yolk) appears once per view. Destructive buttons always state the count ("Move 142 files to Trash"), never just "OK". The label follows the OS: Trash (macOS, Linux), Recycle Bin (Windows), Prullenmand / Prullenbak in Dutch.
